# 副业前端模拟器 · ViceWork Simulator

一个纯前端（零后端、零依赖、零构建）的「假装接单 + 应试训练」小应用。

## 玩法

1. 在任务池里挑一个模拟前端项目，点「接这个单」
2. 中间工作台开始跑虚拟工时倒计时（演示模式：1 秒 = 1 分钟）
3. 在「项目难度拆解 / 模拟面试追问」里补上你最怕被问的点
4. 点「生成模拟追问」，得到「追问 + 质疑点 + 回答提示」的训练清单
5. 倒计时结束自动验收，虚拟收益入账，收益/完成数/连续天数写入 localStorage

## 两种追问生成模式

- **本地免费模拟**：无需任何配置，内置题库会结合你填的难点、质疑点和项目背景生成问题
- **AI 接口生成**：填入兼容 OpenAI 格式的 API Key 即可（默认 DeepSeek：`https://api.deepseek.com/v1/chat/completions` + `deepseek-chat`）
  - Key 只存在浏览器 localStorage，不会上传到任何第三方
  - 调用失败会自动降级到本地模拟，不会卡住流程

## 技术说明

- 原生 HTML / CSS / JavaScript，无框架、无构建步骤
- 数据全部存在浏览器本地，刷新不丢
- 直接双击 `index.html` 即可运行，也可用任意静态服务器托管

## 本地运行

```bash
python -m http.server 4173
# 打开 http://localhost:4173
```

## 目录

```
index.html    页面结构
styles.css    深色主题样式
app.js        任务、倒计时、结算、追问生成逻辑
```
